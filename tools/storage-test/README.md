# Проверка ksud с официальным менеджером

Этот ZIP распаковывается вручную. Это не модуль и не APK. Он содержит исправленный arm64 ksud, проверку SHA-256, установку с резервной копией и восстановление. Ядро, APK, доверенные подписи и глобальные настройки монтирования не меняются. Работоспособность на телефоне ещё не подтверждена.

1. Верни официальный менеджер YukiSU и убедись, что он видит root. Выдай root терминалу, например уже используемому Termux. В настройках менеджера выключи автоматическое обновление ksud; не нажимай ручное обновление ksud во время проверки. После повторной авторизации через SuperKey менеджер также может восстановить свой бинарник.
2. Распакуй архив, например в `/sdcard/Download/yukisu-storage-test`. Выполни в авторизованном терминале:

```sh
su -c 'sh /sdcard/Download/yukisu-storage-test/ksud-test.sh install'
```

Скрипт сверит хэш и UAPI ядра, сохранит текущий `/data/adb/ksud`, установит новый файл атомарным переименованием с контекстом `ksu_file`. При повторной установке существующая резервная копия не перезаписывается. Затем перезагрузи телефон вручную. Не запускай новый бинарник только командой Kagami: эта команда может обратиться к уже работающему старому демону.

3. Проверь режим OverlayFS с ext4, затем отдельно с EROFS. Сними bugreport и проверь `/odm/etc` и `/odm/lib64` в активных монтированиях и запуск камеры. Само отсутствие ошибки не доказывает подмену файлов. После загрузки:

```sh
su -c 'sh /data/adb/ace5-ksud-test/ksud-test.sh status'
```

Если официальный менеджер предупреждает о несовпадении ksud, это ожидаемо для тестового бинарника. Сравни хэш с `ksud.sha256`; восстановление встроенного бинарника отменит тест.

Откат из авторизованного терминала:

```sh
su -c 'sh /data/adb/ace5-ksud-test/ksud-test.sh restore'
```

После отката также нужна перезагрузка. Резервная копия сохраняется. Если Android не загружается, нужен ранее доступный способ доступа к расшифрованному `/data` через recovery/root ADB: скопировать `/data/adb/ace5-ksud-test/original` в `/data/adb/ksud`, восстановить root:root, 0755 и `u:object_r:ksu_file:s0`. Обычный safe mode модулей не гарантирует откат заменённого ksud. Не начинай тест без доступного способа восстановления. APK нашего форка для этой проверки не нужен.

Сборка архива на компьютере: `python tools/storage-test/package.py path/to/ksud out/yukisu-storage-test.zip`. Сюда передаётся бинарник из успешного Actions с исправлениями образов. Скрипт установки проверен статически, запуск и откат на телефоне требуют отдельного испытания.
